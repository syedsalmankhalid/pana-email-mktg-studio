# Skills I chose

Searched on skills.sh on 2026-11-09 for: "email marketing", "email sequence", "campaign plan", "resend". Star counts are GitHub repository stars. Install counts are from skills.sh. Nothing has been installed.

## Use these

**1. anthropics/knowledge-work-plugins, skill `campaign-plan`** (also `email-sequence` in the same repo)
Published by Anthropic, and its repository has about 35,000 stars. It has about 3,400 installs. Both skills exist in the repository today. This is the planning skill the lab uses in Step 4. It writes a full campaign brief with a calendar and metrics, which is what our plan needs.

**2. resend/resend-skills, skill `resend`**
Published by Resend, the email service we send through. It has about 24,400 installs, and the skill exists in the repository (version 3.17.0). It explains the gotchas for sending: idempotency keys, webhook checks and template syntax. The repository has only about 211 stars, which is low for a big company. I still recommend it because it is official and actively updated, and because the install count is high.

## Avoid these

**1. caffeinelabs/skills, skill `extension-email-marketing`**
It shows about 30,700 installs, but its GitHub repository has only 2 stars. That gap between installs and stars is a warning sign. Installs can be inflated, and a repository with almost no stars has almost no public review. I would not trust it with customer email.

**2. mattpocock/skills, skill `grill-with-docs`**
It shows about 1.3 million installs, the highest in the results, but it is not an email skill. It turned up because the search matched "campaign plan". A large install count does not mean a skill is right for the job. Check that the description matches what you need.

## How I decided

1. **Who published it?** Prefer an official publisher (Anthropic, Resend) or a repository with many stars. Be wary of an unknown publisher with a large install count.
2. **Stars against installs.** A large gap, such as tens of thousands of installs with only a handful of stars, is a warning sign.
3. **Does it still exist, and does it do what it says?** Names change. In this check, `coreyhaines31/marketingskills@email-sequence` and `resend/resend-skills@send-email` still appeared in search results, but their folders no longer exist in the repositories. Open the repository and confirm the folder before installing.
